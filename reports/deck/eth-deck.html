§4  Modeling

The split is temporal, not random

Scam operations run clusters of sibling wallets. A random split puts siblings on both sides, and the model recognises the cluster instead of generalising.

Fig. 3 — addresses ordered by first on-chain appearance. Learn from what is known; score what came later.
§4  Leakage

The feature that could have leaked

neighbour_risk_ratio asks “what fraction of my labelled neighbours are illicit?” Computed over all labels, it leaks the answer outright.

So graph.py takes visible labels as an argument, and training passes the training split’s labels only.

PINNED BY UNIT TESTS — including that an address can never read its own label back through a self-loop.

§5  Graph neural network

What if the model reads the graph itself?

A two-layer GraphSAGE over all 44,432 nodes — including unlabelled neighbours — given no graph features at all. It has to rediscover what network context means by passing messages along the edges.

§6  Evaluation

Is the signal real?

Licit addresses were sampled from random blocks, so busy addresses are over-picked: 61% hit the 100-transaction cap, against 8% of illicit ones.

Fig. 5 — within activity-matched pairs, activity carries no information by construction — and F1 does not drop. The confound is genuine but not load-bearing.
